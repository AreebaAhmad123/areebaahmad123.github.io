Court judgment search

A pipeline that scrapes court judgments, turns the PDFs into Markdown, extracts metadata with an LLM and stores everything in AWS S3. A Weaviate index with hybrid search and reranking helps people find the right judgment. Built court-agnostic, so adding a court doesn’t mean rewriting the core.

Python, Groq, Weaviate, FastAPI, AWS S3

Ring Design Recommendation System

Show it a ring and it finds the most similar designs in a jewelry catalog. Images become DINOv2 embeddings, searched through an HNSW index. I compared two fine-tuned models using Recall@K and mAP@K.

PyTorch, DINOv2, HNSW, FastAPI

Real-Time Vehicle Smoke Detection and Reporting

My final year project: a YOLOv8 model trained on 58,000+ annotated smoke and fire images that reaches over 85% mAP.

YOLOv8, PyTorch, OpenCV, Roboflow

01 — About

I'm a final-year IT graduate from PUCIT Lahore with a compulsion for building systems that run themselves. My work spans computer vision, agentic LLM pipelines, MLOps automation, and backend API engineering.

In my current role as a Research Assistant at PUCIT, I architected MCPValidator3 — a 4-microservice agent framework communicating via A2A JSON-RPC 2.0, with MCP servers built on fastmcp 2.13.1. I also shipped an autonomous MLOps auditor that clones repos, runs AI-powered analysis via Gemini 2.5 Flash, generates fixes, and opens GitHub PRs — fully orchestrated through n8n.

I co-authored an IEEE research paper on my FYP: a YOLOv8 system trained on 58,000+ annotated images for real-time carbon emission detection from vehicle smoke and fire. Six checkpoint iterations. >90% mAP.

I care about systems that are observable, modular, and actually deployable — not just notebooks that work on my machine.
